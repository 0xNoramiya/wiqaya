Wiqaya

Your screen time, redeemed.

A small Chrome extension that watches the time you spend on the sites you cannot put down — and, when the hour you set has passed, opens a single verse of the Qur’ān before letting you continue.

View on GitHub · Install

For the Quran Foundation Hackathon · MMXXVI

I  ·  The method

How it works

Four small movements, repeated patiently.

i.

Add the sites

Name the places you keep returning to without intending to: twitter.com, reddit.com, youtube.com, or any others. They become your watch list.

ii.

Set a limit

Choose a number of minutes — between one and sixty — that feels honest. A single global limit, or a different one per site.

iii.

Browse, while it counts

A small badge on the toolbar keeps track. When you change tabs, lock your screen, or step away, it pauses. Nothing is sent anywhere.

iv.

Pause, and read

When the limit is met, a verse opens over the page. Read the Arabic, reveal the translation, listen if you wish, and carry on with a few extra minutes of quiet.

II  ·  What it offers

Designed for contemplation

An index of the smaller things, in the order they were made.

Arabic in Uthmani script i

Set in Amiri, full-width, the verse is the page. The translation arrives only when you ask for it.

Tap to reveal translation ii

English first hidden behind a small gesture, so the eye reads the Arabic before the mind reaches for meaning.

Audio recitation iii

A small audio plate with a quiet waveform; choose between five reciters, or set the verse to play automatically.

Bookmarks iv

Save the verses you wish to return to. They are kept under Saved in the popup, away from the rush of the day.

Live dashboard v

Today’s verses, time per site, and the streak — three numbers and nothing more.

Light and dark themes vi

A warm, paper-like light mode for the day; a hushed dark mode for the night.

Reading streaks vii

A gentle counter of days kept. Not a leaderboard, not a grade — only a record of one’s own consistency.

Engagement gating viii

The “Continue Browsing” button waits, by design, until you have actually engaged with the verse. No reflex dismissal.

Considered detail ix

Quiet typography, restrained colour, hairline rules, and a Shadow-DOM overlay that never bleeds into the host page.

IV  ·  Colophon

Set & built

The materials of this small work.

Built upon Chrome Manifest V3, with a service worker that keeps quiet most of the day and rouses only on the alarm of a tick.

Set in Amiri for the Arabic, Cormorant Garamond for headings, and EB Garamond for body — all delivered by Google Fonts.

Authored in React 18 and TypeScript, styled with Tailwind CSS v4 and a small handful of bespoke rules, bundled by Vite 6 through @crxjs/vite-plugin.

Verses, translations, audio, and the user record arrive from the Quran Foundation’s Content and User APIs. The overlay lives inside a Shadow DOM, so no host page can reach it.

V  ·  To begin

Install Wiqaya

Seven small steps, the last of which is to start.

From source

For developers and the curious.

  1. Clone the repository: git clone https://github.com/0xNoramiya/wiqaya.git
  2. Install the dependencies: cd wiqaya && npm install
  3. Create a .env file with your Quran Foundation API credentials.
  4. Build the extension: npm run build
  5. Open Chrome, go to chrome://extensions, and enable Developer Mode.
  6. Click Load unpacked and select the dist/ folder.
  7. Pin Wiqaya to your toolbar, add a site, and choose your hour.
