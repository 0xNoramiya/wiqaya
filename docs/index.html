How It Works
Four simple steps

Wiqaya works quietly in the background, turning your browsing habits into moments of Quran connection.

1
➕
Add Sites
Add distracting domains like twitter.com, reddit.com, youtube.com to your watch list.
2
⏱️
Set Limits
Configure time limits from 1 to 60 minutes — globally or per site.
3
🌐
Browse Normally
Wiqaya tracks time in the background with a live badge counter on the extension icon.
4
📖
Reflect
When time's up, an immersive Quran verse overlay appears — read, listen, reflect.
Features
Designed for contemplation

Every detail is crafted to make Quran engagement feel natural and beautiful.

🕌
Arabic Text in Uthmani Script
The Arabic text takes center stage, rendered in the beautiful Amiri font with proper Uthmani script.
📜
Reveal Translation
Arabic first, then tap to reveal the English translation. Engage with the text before moving on.
🎧
Audio Recitation
Built-in audio player with waveform visualization. Choose from 5 renowned reciters. Auto-play option available.
❤️
Bookmark Verses
Save verses that resonate with you. Access your bookmarks anytime from the popup.
📊
Live Dashboard
Real-time stats: verses read today, time per site, reading streak — all updating live.
🌗
Dark & Light Themes
Warm paper-like light mode inspired by a physical mushaf. Rich dark mode for nighttime browsing.
🔥
Reading Streaks
Track your consecutive days of Quran engagement. Build a habit through gentle consistency.
🔒
Engagement Gating
"Continue Browsing" only appears after interacting with the verse — no quick dismiss.
✨
Beautiful UI
Gold particles, animated borders, smooth transitions, and glass-morphism throughout.
Quran Foundation API Integration
Powered by trusted sources

Wiqaya uses both the Content API and User API from the Quran Foundation.

📖 Content API (v4)
No login required — client credentials
GET /api/v4/verses/random
GET /api/v4/quran/translations/{id}
GET /api/v4/recitations/{id}/by_ayah/{key}
GET /api/v4/chapters
🔐 User API (v1)
OAuth2 PKCE — bookmarks, streaks, sessions
POST /auth/v1/bookmarks
GET /auth/v1/bookmarks
POST /auth/v1/reading-sessions
GET /auth/v1/streaks

Install Wiqaya

  1. Clone the repository: git clone https://github.com/0xNoramiya/wiqaya.git
  2. Install dependencies: cd wiqaya && npm install
  3. Create a .env file with your Quran Foundation API credentials
  4. Build the extension: npm run build
  5. Open Chrome → chrome://extensions → Enable Developer Mode
  6. Click Load unpacked and select the dist/ folder
  7. Pin Wiqaya to your toolbar and start adding sites!
